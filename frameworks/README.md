# AI agent security and governance mappings

Initial mapping targets:

- NIST AI Risk Management Framework
- NIST AI Agent Standards Initiative identity and authorization work
- OWASP Top 10 for Agentic Applications 2026
- OWASP Agent Control Standard
- ISO/IEC 42001
- MITRE ATLAS
- AIUC-1
- SOC 2 and ISO/IEC 27001 supporting controls

Each mapping record must state the source version, requirement identifier, assurance field, test or evidence type, mapping rationale, reviewer, confidence, date and status. `DOCUMENTED`, `IMPLEMENTED`, `TESTED` and `VERIFIED` remain separate states.

A crosswalk establishes traceability only. It does not establish legal compliance, certification, auditor acceptance or equivalence between frameworks.
